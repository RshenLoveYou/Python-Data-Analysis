# 回归分析课后作业思考题

## 1. 代数证明：一元线性回归残差性质
一元线性回归模型：y_i = b0 + b1 * x_i + e_i
残差定义：e_i = y_i - y_i_hat
b0：OLS截距估计值
b1：OLS斜率估计值
y_i_hat：y_i的拟合值

OLS最小化目标：最小化 sum(e_i^2) = sum( (y_i - b0 - b1 * x_i)^2 )

### 证明1：残差之和等于0，sum(e_i) = 0
对b0求偏导，令偏导数等于0：
d[sum(e_i^2)] / db0 = -2 * sum(y_i - b0 - b1 * x_i) = 0
消去常数-2：
sum(y_i - b0 - b1 * x_i) = sum(e_i) = 0
结论：OLS估计下残差总和为0。

### 证明2：残差与自变量乘积之和等于0，sum(x_i * e_i) = 0
对b1求偏导，令偏导数等于0：
d[sum(e_i^2)] / db1 = -2 * sum(x_i * (y_i - b0 - b1 * x_i)) = 0
消去常数-2：
sum(x_i * (y_i - b0 - b1 * x_i)) = sum(x_i * e_i) = 0
结论：OLS估计下自变量与残差乘积之和为0。

注：以上两个等式为OLS正规方程。

## 2. 思考题：加入纯随机无关特征，R²上升，调整R²下降
公式：
R² = 1 - RSS / TSS
R²_adj = 1 - (RSS/(n-k-1)) / (TSS/(n-1))
TSS：总平方和，样本固定时不变
RSS：残差平方和
n：样本量；k：自变量个数；n-k-1：残差自由度

### 解释
1. 普通R²会上升（或不变）
OLS目标为最小化RSS。新增变量会扩大模型拟合空间，即使新增变量系数取0，RSS也不会变大。当新增变量为纯随机噪声时，模型拟合随机波动，RSS小幅下降。TSS不变，RSS下降，R²上升。R²不对变量数量进行惩罚，增加变量，R²只会上升或保持不变。

2. 调整R²（R²_adj）会下降
调整R²引入自由度惩罚。增加自变量，k增大，残差自由度n-k-1减小。加入无关随机变量时，RSS下降幅度很小，但自由度损失明显，RSS/(n-k-1)变大，最终导致调整R²下降。

总结：普通R²不惩罚变量数量；调整R²利用自由度惩罚多余变量。若新增变量解释能力不足以抵消自由度损失，调整R²将会下降。
